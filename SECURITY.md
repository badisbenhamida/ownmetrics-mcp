# Security policy

Please report vulnerabilities **privately**, not in a public issue: use GitHub's
"Report a vulnerability" button on this repository's Security tab.

Include what you found, how to reproduce it, and its impact. You will get an acknowledgement
within a week. Please do not include anyone's real Garmin key or personal data in a report.

If you believe your own Garmin Personal API key was exposed, delete it in Garmin Connect
(Settings → Personal API) and create a new one; deleting a key revokes every token issued
from it.
